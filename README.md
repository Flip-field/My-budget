# My Budget V1
Mobile-first personal budgeting app.

- Default weekly income: AUD 1,000
- Data stored in browser localStorage
- No opening password
- Budget and Actual Spend columns
- Transactions
- Changeable custom-date reports
- Export/import JSON backups
- PWA service worker for offline use after first load

For GitHub Pages: upload these files to a repository, enable Pages from the repository's Settings > Pages, and open the resulting Pages URL on your phone. Do not commit exported backup files.
